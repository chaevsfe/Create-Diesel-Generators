# Create Fly: Diesel Generators

Oil prospecting and pumpjacks, distillation, diesel engines, chemical sprayers, fueled tools, cement and asphalt.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> George VI. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.3` |
| Mod loader | Fabric Loader `0.20.1` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [Modrinth](https://modrinth.com/project/AfUI0xBG)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-fly-diesel-generators)
- [GitHub releases](https://github.com/chaevsfe/Create-Diesel-Generators/releases)


## Building

```
git clone https://github.com/chaevsfe/Create-Diesel-Generators
cd Create-Diesel-Generators
./gradlew build
```

Requires JDK 25.
